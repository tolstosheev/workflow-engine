## Правила ведения

1. **Схемы — Mermaid.** Исходник лежит в `diagrams/*.mmd`, в документ вставляется
   блоком ` ```mermaid `. Это позволяет править схему без перерисовки картинки.
2. **Решение с последствиями — ADR.** Обоснование не живёт в переписке: оно
   оформляется в `adr/NNNN-короткое-описание.md`.
3. **Документ обновляется тем же коммитом, что и код.** Расхождение кода и
   документации — дефект, а не мелочь.
4. **На принятый ADR не редактируют.** Новый контекст — новый ADR, в старом
   меняется только строка `Status` (`Superseded by ADR-XXX`).

Подробные правила — в разделе «Правила ведения документации» файла
[`../AGENTS.md`](../AGENTS.md).
